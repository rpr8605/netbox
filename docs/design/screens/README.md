# Screen pictures

Rendered pictures of every approved screen, for reference and for explaining the product.
All data shown is sample data.

- `Configurator/`: the 8 Configurator screens (build bench tool).
- `Tech_Console/`: the 7 tech console screens (service desk). Design files are in `docs/design/tech-console/`.
- `Beacon_Relay_Screens.pdf`: all 15 screens, one per page.

Known layout fix: on the master board (`Console_01_Master_board.png`), the service grid runs about
80 px past the right edge of its card at 1440 px wide. The build should fit it inside the card.
